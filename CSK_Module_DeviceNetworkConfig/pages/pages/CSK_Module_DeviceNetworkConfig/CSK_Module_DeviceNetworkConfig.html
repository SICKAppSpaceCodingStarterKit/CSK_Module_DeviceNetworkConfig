Not possible to set configuration via this module. There might be other possiblities (e.g. OS or ControlCenter). To delete a nameserver, please select a DNS entry from the list and press 'Remove'.
A maximum of three nameserves can be added. Nameservers that are added automatically via DHCP cannot be deleted.
Please note that the DNS entries can only be persistent, if the app 'CSK_Module_PersistentData' is loaded. Important: With a wrong setup this might make your device inaccessible. So test your setup first with a limited time period! If it works as expected, set the "Stop bridge" timer to "0" and save the configuration. It is not possible to add ALL interfaces at once to the bridge. To change an existing bridge setup you first need to delete the old bridge (deselect all interfaces and apply), reconnect to the device and create a new bridge. New config NOT accepted ...
